# Elm Simple CRM

`Elm Simple CRM` یک CRM سبک، فارسی و راست‌چین است که با PHP خام، MySQL، HTML، CSS و JavaScript ساده ساخته شده است. هدف پروژه این است که بدون فریم‌ورک‌های سنگین، یک سیستم قابل فهم، قابل نصب و قابل توسعه برای مدیریت مشتریان، مخاطبین، فرصت‌های فروش، پیگیری‌ها، تیکت‌ها و گزارش‌های پایه در اختیار داشته باشید.

## تقدیم

این پروژه تقدیم به همه کسانی که برای شروع، رشد یا نظم دادن به کارشان به یک CRM ساده، شفاف و قابل فهم نیاز دارند؛ کسانی که نمی‌خواهند در پیچیدگی نرم‌افزارهای بزرگ گم شوند و فقط می‌خواهند مشتری، پیگیری، فروش و پشتیبانی را مرتب‌تر مدیریت کنند.

## نصب سریع با نصب‌کننده

1. فایل‌های پروژه را روی هاست یا سرور خود آپلود کنید.

پوشه `crm/public` باید به عنوان document root وب‌سایت یا ساب‌دامین تنظیم شود. اگر هاست شما اجازه تنظیم document root نمی‌دهد، می‌توانید پروژه را در یک پوشه مثل `crm` قرار دهید و آدرس نصب را از همان مسیر باز کنید.

```text
https://your-domain.com/install.php
```

یا اگر پروژه داخل پوشه `crm` قرار گرفته است:

```text
https://your-domain.com/crm/public/install.php
```

2. مطمئن شوید PHP 8+ و MySQL/MariaDB روی سرور فعال است.

3. نصب‌کننده را در مرورگر باز کنید.

4. اطلاعات دیتابیس، حساب مدیر سیستم و تنظیمات اولیه سامانه را وارد کنید.

5. اگر گزینه «داده نمونه اولیه ایجاد شود» را فعال کنید، چند مشتری، مخاطب، فرصت و فعالیت نمونه ساخته می‌شود. اگر این گزینه را فعال نکنید، فقط تنظیمات پایه و حساب مدیر ساخته می‌شود.

6. بعد از نصب، فایل زیر ساخته می‌شود و نصب‌کننده غیرفعال خواهد شد:

```text
crm/database/install.lock
```

برای اجرای دوباره نصب در محیط امن، این فایل را حذف کنید.

## نصب روی هاست اشتراکی

اگر از هاست اشتراکی استفاده می‌کنید:

- محتوای پروژه را در مسیر دلخواه آپلود کنید.
- اگر امکان تنظیم document root دارید، آن را روی `crm/public` بگذارید.
- اگر امکان تنظیم document root ندارید، آدرس‌های سامانه از مسیر `crm/public` در دسترس خواهند بود.
- فایل `crm/app/config/database.php` خارج از مسیر public قرار دارد و مستقیما از وب قابل دسترسی نیست.

## نصب روی سرور اختصاصی یا VPS

برای Apache یا Nginx، document root دامنه یا ساب‌دامین را روی مسیر زیر تنظیم کنید:

```text
crm/public
```

بعد از نصب، آدرس‌های اصلی به شکل زیر خواهند بود:

- صفحه خانه: `https://your-domain.com/home.php`
- ورود کاربران داخلی: `https://your-domain.com/login.php`
- پرتال مشتری: `https://your-domain.com/portal.php`
- نصب اولیه: `https://your-domain.com/install.php`

## نصب دستی دیتابیس

اگر نمی‌خواهید از نصب‌کننده استفاده کنید، فایل‌های SQL را به ترتیب import کنید:

```sql
SOURCE /path/to/crm/database/schema.sql;
SOURCE /path/to/crm/database/seed.sql;
```

یا از phpMyAdmin:

1. فایل `crm/database/schema.sql` را Import کنید.
2. سپس فایل `crm/database/seed.sql` را Import کنید.

بعد از نصب دستی، مشخصات اتصال دیتابیس را در این فایل تنظیم کنید:

```text
crm/app/config/database.php
```

نمونه تنظیمات:

```php
return [
    'host' => 'your-db-host',
    'port' => 3306,
    'dbname' => 'simple_crm',
    'username' => 'root',
    'password' => '',
    'charset' => 'utf8mb4',
];
```

## حذف داده‌های نمونه

اگر هنگام نصب، داده نمونه ساخته‌اید یا از `seed.sql` استفاده کرده‌اید و بعدا خواستید داده‌های نمونه را حذف کنید، فایل زیر را در phpMyAdmin یا MySQL اجرا کنید:

```sql
SOURCE /path/to/crm/database/remove_sample_data.sql;
```

این فایل فقط مشتریان نمونه با کدهای `ELM-1001`, `ELM-1002`, `SC-1001`, `SC-1002`, `SC-1003`, `SC-1004` و اطلاعات وابسته به آن‌ها را حذف می‌کند. حساب مدیر و تنظیمات سامانه باقی می‌ماند.

## ورود پیش‌فرض

در صورت استفاده از `seed.sql`:

```text
Email: admin@simple-crm.local
Password: Admin@12345
```

رمز عبور در دیتابیس فقط به صورت hash شده ذخیره می‌شود.

## پرتال مشتری

مخاطب‌هایی که دسترسی پرتال برای آن‌ها فعال شده باشد، می‌توانند از مسیر زیر وارد شوند:

```text
https://your-domain.com/portal.php
```

حساب نمونه پرتال:

```text
Email: reza.mohammadi@example.com
Password: Contact@12345
```

در بخش «مخاطبین» می‌توانید برای هر فرد دسترسی پرتال را فعال کنید، رمز عبور بدهید و امکان ثبت تیکت را در اختیار او بگذارید.

## تاریخ شمسی و میلادی

در دیتابیس، تاریخ‌ها میلادی ذخیره می‌شوند. در رابط کاربری، تاریخ‌ها شمسی نمایش داده می‌شوند.

نمونه ورودی شمسی:

```text
1405/03/12
```

قبل از ذخیره، سیستم تاریخ شمسی را به میلادی تبدیل می‌کند.

## پیامک

در بخش «تنظیمات» می‌توانید اطلاعات اتصال به sms.ir را وارد کنید:

- API Token
- شماره خط ارسال‌کننده
- موبایل مدیر
- مسئول پیش‌فرض تیکت
- فعال یا غیرفعال بودن پیامک‌های مختلف

رویدادهای پیامکی:

- ثبت تیکت جدید و اطلاع به مسئول رسیدگی
- پاسخ به تیکت و اطلاع به ثبت‌کننده تیکت
- ارسال نام کاربری، رمز عبور و لینک عمومی پرتال برای مخاطب
- خلاصه روزانه CRM و تیکت‌ها برای مدیر

برای پیامک اطلاعات ورود پرتال، متن پیام از بخش تنظیمات قابل تغییر است و می‌تواند از Placeholderهای زیر استفاده کند:

```text
{app_title}
{contact_name}
{customer_name}
{email}
{password}
{portal_url}
```

برای خلاصه روزانه، فایل زیر را با Task Scheduler ویندوز یا cron سرور اجرا کنید:

```text
php /path/to/crm/cron/daily_summary.php
```
